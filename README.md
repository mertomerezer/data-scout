# data-scout

Proje açıklaması eklenecek.

## Yapı

- `src/`: Python kaynak dosyaları (`main.py`)
- `data/raw/`: Ham veriler
- `data/interim/`: Ara işlem verileri
- `data/processed/`: İşlenmiş veriler
- `notebooks/`: Analiz ve denemeler
- `tests/`: Testler
- `config/`: Proje ayarları
- `docs/`: Belgeler
- `reports/`: Raporlar
